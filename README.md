# CyberTrace - Python Digital Forensic Investigation Toolkit

A Python-based digital forensics toolkit for evidence acquisition, preservation, and forensic analysis. Built as Final Year Project for BSc Cyber Security, Skyline University Nigeria.

> This toolkit demonstrates core DFIR principles: Chain of Custody, Evidence Integrity (MD5/SHA256), and Timeline Analysis.

### 🔍 Key Features
- **Forensic Imaging:** Create forensically sound disk images
- **Hash Verification:** MD5 & SHA256 validation for chain of custody
- **File Recovery:** Deleted file carving and metadata extraction
- **Log Timeline:** Automated artifact timeline generation
- **Reporting:** Auto-generates forensic investigation reports

### 🛠️ Built With
Python 3.x | hashlib | os | pathlib | datetime | Logging
